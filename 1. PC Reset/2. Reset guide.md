# Reset Guide

> [!CAUTION]
> Before installing Windows create a .reg file in your USB stick and paste :

```reg
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\WindowsUpdate]
"ExcludeWUDriversInQualityUpdate"=dword:00000001

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\DriverSearching]
"SearchOrderConfig"=dword:00000000

[HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows\CurrentVersion\Device Metadata]
"PreventDeviceMetadataFromNetwork"=dword:00000001
```

1. Install Windows with network unplugged
2. When you're in OOBE setup, press 'SHIFT + F10'
3. A CMD tab will open, then enter this command :
```
    oobe\bypassnro
```
4. Proceed to normal setup without a microsoft account
5. Once on the desktop, run the `.reg` file from the USB stick
6. You can restart your PC and plug your network cable back in
