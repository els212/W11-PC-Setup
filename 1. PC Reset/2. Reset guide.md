# Reset Guide

> [!CAUTION]
> You should follow this guide to install Windows without a microsoft account and avoid auto drivers downloads.

1. Install Windows with network cable unplugged.
2. When you're in OOBE setup, press 'SHIFT + F10'.
3. A CMD window will open, then enter this command:
```cmd
oobe\bypassnro
```
4. Proceed to normal setup without a microsoft account.
5. Once on the desktop, run the `.reg` file from the USB stick.
6. Restart your PC and plug your network cable back in.
